# UI/UX review

Use for user-interface changes, frontend review, form design, responsive issues, or accessibility concerns.

## Checklist

- Clear hierarchy, consistent typography/spacing, readable contrast, and modern but purposeful presentation.
- Deliberate desktop, laptop, tablet, and mobile behavior; do not merely shrink desktop UI.
- Loading, empty, error, success, disabled, focus, and validation states are clear.
- Forms have labels, accessible errors, useful focus behavior, and confirmation where needed.
- Semantic HTML, keyboard navigation, visible focus indicators, and non-color-only state cues are present.
- Animation communicates feedback, transition, or state change rather than decoration.

Inspect the project design system and existing components before introducing a new pattern. Propose material component or interaction changes before implementation.
